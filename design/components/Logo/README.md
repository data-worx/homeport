# Logo

The Homeport mark is a container docked between two quay posts above calm water: a module that has arrived in your own harbor. Use the lockup "Homeport by data-worx" where the maker matters (landing hero, footer, login); use the wordmark or the icon alone everywhere else.

**Files** (group Logos): `homeport-lockup.svg` (light grounds), `homeport-lockup-on-dark.svg`, `homeport-lockup-mono-ink.svg`, `homeport-lockup-mono-white.svg`, `homeport-wordmark-navy.svg`, `homeport-wordmark-white.svg`, `homeport-icon.svg`, `favicon.svg`, `homeport-icon-mono-ink.svg`, `homeport-icon-mono-white.svg`, PNGs 16 / 32 / 180 / 512.

- Clear space: at least the icon's post width x 2 (one quarter of the icon height) on every side.
- Minimum sizes: icon 16 px (use `favicon.svg`, which drops the container ribs), lockup 45 px tall (keeps the byline at 8 px or more), wordmark 16 px tall.
- "by data-worx" is the data-worx endorsement byline; the rule is binding and comes from the data-worx design system (brand book § Endorsement byline, `components/Endorsement`). It always keeps the data-worx colours (light grounds: letters `#18181a`, hyphen `#ffa500`; dark grounds: letters `#ededea`, hyphen `#ffac34`; mono only in one-colour lockups). Never recolour it to Homeport's ink, ink-muted or accent, never retype it.
- Byline height (top of the d to baseline) = 0.4 × wordmark cap height, never under 8 px; gap below the wordmark baseline = 0.5 × cap height; left edge on the wordmark, not the icon. Low headers: byline to the right, baselines aligned, gap = 1 × cap height.
- Use the monochrome files for print, embossing, single-color merch, and the portal app bar when space is tight.
- The wordmark is Instrument Sans SemiBold, converted to outlines. Never retype it.

**Don't**: recolour the byline or set it in Instrument Sans, recolor the container (it is always `accent`, the harbor light), add port/starboard dots to the mark, put the color icon on photos, stretch, rotate, add shadows, or place anything that resembles a whale or another brand's logo next to it.
