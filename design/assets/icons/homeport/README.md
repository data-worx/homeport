# Icons — Homeport platform concepts

Custom icons on the Lucide grid: 24 × 24, 2 px stroke, round caps and joins, `stroke="currentColor"`. Inline them (or use `HomeportIcons.Platform.*` in Blazor) so they take the text color; as `<img>` they render black.

- `hp-module` — a container with a lifting spreader: a module that docks.
- `hp-tenant` — a building with a flag: a department or customer.
- `hp-plan` — a sheet with three tiers: a plan.
- `hp-client` — a window with `< >`: an API client.
- `hp-meter` — a three-wheel counter: a meter that counts units.
- `hp-quota` — a filled bar with a limit line: a quota.
- `hp-registry` — a ledger of entries: the module registry.
- `hp-heartbeat` — a pulse ending in a beacon: heartbeats.
