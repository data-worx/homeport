# Lucide subset

The Lucide icons the portal and site use, copied unchanged from lucide-static 1.59.0 (ISC License, © Lucide Contributors; notice in Licenses). Single ink via `currentColor`: inline them or use `HomeportIcons.Lucide.*`. Use the full Lucide set for anything new, same stroke and size rules.

Status icons are fixed: `circle-check` success/healthy, `triangle-alert` warning/degraded, `circle-x` error/unreachable, `info` info, `arrow-down-to-line` draining.
